CSV to JSON and JSON to CSV converter

Turn spreadsheet-style data into JSON, or JSON into CSV.

How to use it

  1. Paste CSV with a header row, or a JSON array of objects.
  2. Click CSV → JSON or JSON → CSV.
  3. Copy the result.

Example

name,age
Ada,36
Linus,55

Frequently asked questions

Does the first row have to be headers?

Yes. For CSV → JSON, the first row supplies the key names for every object.

What if a value contains a comma?

Wrap it in double quotes, like "Lovelace, Ada". Quoted fields are read correctly.
