JSON to YAML and YAML to JSON converter

Turn JSON into readable YAML, or YAML into JSON.

How to use it

  1. Paste JSON or YAML into the input box.
  2. Click JSON → YAML or YAML → JSON.
  3. Copy the converted result.

Frequently asked questions

Why use YAML instead of JSON?

YAML is easier to read and allows comments, so it is common in configuration files. JSON is stricter and more widely used between programs.

Is YAML indentation important?

Yes. YAML uses indentation to show structure, so keep spaces consistent. Tabs are not allowed for indentation.
