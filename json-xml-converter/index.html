JSON to XML and XML to JSON converter

Switch between JSON and XML with one click.

How to use it

  1. Paste JSON or XML into the input box.
  2. Click JSON → XML or XML → JSON.
  3. Copy the converted result.

Example

{"user":{"name":"Ada","age":36}}

Frequently asked questions

How are XML attributes converted?

Attributes become keys that start with @, and mixed text becomes a #text key.

What happens to JSON arrays?

Each array item becomes a repeated XML element with the same name.
