Free JSON formatter and validator

Paste messy JSON and get clean, readable output, or squeeze it into one line.

How to use it

  1. Paste your JSON into the input box.
  2. Click Format, Minify or Sort keys.
  3. Copy the result. If the JSON is invalid, the message shows the line and column of the problem.

Example

{"name":"Ada","tags":["math","code"]}

Frequently asked questions

Is my JSON uploaded anywhere?

No. All processing happens in your browser, so your data never leaves your device.

Why does my JSON show an error?

Common causes are trailing commas, single quotes instead of double quotes, and keys without quotes. The error message points to the position.
