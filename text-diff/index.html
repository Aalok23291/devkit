Text diff checker

Paste two versions of a text and see exactly what changed.

How to use it

  1. Paste the original text on the left and the changed text on the right.
  2. Click Compare.
  3. Green lines were added and red lines were removed.

Frequently asked questions

What does the diff compare?

It compares line by line, so a small change inside a line shows as one removed line and one added line.

Is there a size limit?

Up to 3,000 lines on each side, which keeps the page fast.
