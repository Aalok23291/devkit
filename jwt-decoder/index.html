JWT decoder

Read what is inside a JSON Web Token.

How to use it

  1. Paste your token, which has three parts separated by dots.
  2. Click Decode.
  3. Read the header and payload. If the payload has an exp value, the expiry time is shown.

Example

eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIxMjMiLCJuYW1lIjoiQWRhIn0.signature

Frequently asked questions

Does this verify the signature?

No. It only decodes the readable parts. Verifying a signature needs the secret or public key and should be done on your server.

Is it safe to paste a token here?

Decoding happens in your browser and nothing is uploaded. Still, avoid sharing live tokens with anyone you do not trust.
